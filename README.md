# 🗂️ 나만의 프롬프트 관리 프로그램

## 📌 소개
흩어져 있던 AI 프롬프트를 한 곳에 모아 관리하는 콘솔 프로그램입니다.
카테고리 분류, 키워드 검색, 즐겨찾기 기능을 제공합니다.
Python 기초 문법과 Git 버전 관리를 연습하기 위해 만들었습니다.

## 🛠️ 개발 환경
- Python 3.10 이상  <!-- 터미널에 python --version 쳐서 나온 숫자로 바꾸기 -->
- Visual Studio Code
- Git / GitHub

## ▶️ 실행 방법
1. 저장소 내려받기
   git clone [내 GitHub 저장소 주소를 여기에 붙여넣기]
2. 폴더 이동
   cd prompt-manager
3. 프로그램 실행
   python main.py

## ✨ 기능 목록
- 프롬프트 추가
- 프롬프트 목록 보기
- 카테고리별 조회
- 프롬프트 검색 (제목/내용 키워드)
- 프롬프트 상세 보기
- 즐겨찾기 추가/해제
- 즐겨찾기 목록 보기
- 종료

## 🗂️ 프롬프트 카테고리
- 텍스트 생성 : 글쓰기, 요약 등
- 이미지 생성 : 그림, 썸네일 등
- 영상 생성 : 영상, 스크립트 등
- 페르소나 : 전문가 역할 설정
- 자동화 : 반복 작업 자동화
- 기타 : 그 외 프롬프트
